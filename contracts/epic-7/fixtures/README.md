intentionnellement sans fixture JSON. Les réponses synthétiques se trouvent
exclusivement dans `test/sonde_rangement_test.dart`.

anonymisé, attribuer un identifiant de preuve sans données personnelles, puis
lier le fichier au build et aux observations interclients dans `verification.md`.
